# 外置大脑：当场记 & 先查再答

用户的所有项目共用一个大脑。先探测大脑在哪台机器上：

- 存在 `<公司机大脑仓库路径>` → 公司机，用这个
- 存在 `<家用机大脑仓库路径>` → 家用机，用这个
- 都不在 → 告诉用户大脑不在这台机器上，本次跳过，不要在别的地方新建

## 记：对话中出现值得学的内容时，主动做，不用问

往 `<大脑>/raw/公司学习/对话即记/<今天 YYYY-MM-DD>.md` **追加**（目录或文件不存在就新建；新建文件时加三行 frontmatter：`source: 对话实时记录（各项目会话）`、`type: work-note`、`date: <当天>`）。条目格式：

```markdown
- HH:MM [项目名或主题] 一到几行：学到什么 / 踩了什么坑 / 和谁对接定了什么
```

- 只追加，**不做 git 提交**——每晚 17:40 的查漏工作流会统一整理、展开成结构化日结并提交推送
- 每条要短，当晚日结负责展开；一次对话记多条没问题
- 判断标准（信任你的判断）：三个月后回看，这条能帮用户面试、排坑或理解原理吗？能就记
- 边界：不碰这个文件之外的任何 raw/ 文件，不写 wiki/（那是用户说「摄取」之后的阶段）

## 查：聊到相关主题时，先查再答

读 `<大脑>/wiki/index.md` 按主题找页面，引用页面回答并注明来源；wiki 覆盖不足时可以读 raw/ 原文补充。库里没有就直说没有，不编。
