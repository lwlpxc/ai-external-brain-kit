# 课程笔记记录

把用户提供的课程视频内容（口述转写、字幕、笔记）归档进知识库 raw/，并附一段 AI 速记。**本技能只做归档+速记，不做摄取**（不写 wiki/，不建概念页）。

## 执行步骤

1. **确认课程元信息**：从用户话术或转写内容中判断课程名、第几讲、标题。缺什么问什么，一次问清（如："这是《FOC电机控制》第 2 讲对吧？标题叫什么？"）。课程名用用户叫法。
2. **写入一个文件**到 仓库根下 `raw/课程/<课程名>/<编号两位>-<标题>.md`（以当前机器的仓库实际路径为根，不写死盘符），编号如 `01`。文件结构：

```markdown
---
source: 课程「<课程名>」第 <N> 讲：<标题>
type: course-note
course: <课程名>
lesson: <N>
recorded: <今天日期>
---

# 第 <N> 讲：<标题>

## AI 速记（AI 生成段，摄取时仅供参考，不作原文引用）

- 用 5~10 条要点提炼本讲核心内容，口语废话全部剔除
- 单独列出：新术语、关键结论、与其他笔记相关处（可写 [[双链]] 提示，但本阶段不建页）
- 转写中可疑的口误/听错词，标注「（转写疑误，原意可能为 X）」
- 结尾列 1~3 条「待消化问题」

## 原文转写

<用户提供的文本原样放入，一字不改>
```

3. **更新台账** 仓库根下 `raw/课程/待摄取.md`：每个课程一行，格式 `- <课程名>：已完成 01-xxx、02-xxx（最新：YYYY-MM-DD）`。新课程追加一行，旧课程更新。这是后续批量摄取的范围依据。
4. **纪律**：
   - 只新增文件，绝不修改 raw/ 下已存在的其他文件
   - 「原文转写」段永远保持用户提供的原文本，不做润色
   - AI 速记必须带「AI 生成段」标注，摄取时摘要以原文为准，速记只当导读
   - 不更新 wiki/log.md（那是摄取阶段的动作）
5. **收尾**：按 AGENTS.md 的 Git 自动提交规则提交推送，提交信息格式：`记课 <课程名> 第N讲：<标题> → raw/课程/`。
6. **摄取时机**：用户说「摄取 <课程名>」（或宣布某阶段学完）时，才把该课程全部讲次按 AGENTS.md 摄取流程整理进 wiki/，摘要页放 `wiki/摘要/<主题分类>/`。
