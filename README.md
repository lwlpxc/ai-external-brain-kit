# AI 外置大脑工作流分享包

一套「和 AI 协作学习/工作」的完整工作流：让 AI 在任何项目的对话里自动帮你**记知识、整理知识、复习知识**，形成 输入 → 沉淀 → 内化 的闭环。

原始环境：ZCode（Claude Code 兼容）+ 任意大模型 + 一个 Git 仓库做知识库（下称「大脑仓库」）。

## 这套东西能干嘛

1. **对话即记**：跟 AI 干活时出现值得记的知识点、踩坑、对接结论，AI 当场记入大脑，不打断工作流、不用你请示
2. **每日日结**（定时 17:40）：AI 自动回溯当天所有对话，查漏补缺写成结构化日结并 git 提交
3. **自动制卡**（定时 18:00）：把当天日结提炼成 3~5 张面试官视角的问答卡
4. **晨间复习**（定时 8:10）：SRS 间隔重复快闪卡（1/2/4/7/15/30 天）+ AI 扮演刁钻面试官对主题深耕追问 8~10 题
5. **知识摄取**：原始笔记 → AI 整理成带双链的 wiki 摘要页 + 概念页，知识长成网络而不是散落的聊天记录
6. **防错觉机制**：AI 回答优先引用你自己的笔记页面，而不是凭模型记忆裸讲——记住不等于会，必须回原文核对

方法论的完整阐述见 `raw笔记/AI与嵌入式结合-学习计划与心得.md`（重点：框架立边界 → Skill 沉淀经验 → 反驳+喂料补盲点 → 强回路验证 → 坑回写迭代）。

## 目录结构

```
skills/                 # 5 个 ZCode 全局技能（复制到 ~/.zcode/skills/ 即生效）
  brain/                # 核心：对话即记 + 先查再答（自动探测大脑仓库位置）
  company-notes/        # 口述公司学习内容 → 归档（活文档/时点记录双轨制）
  course-notes/         # 课程视频转写/字幕 → 归档 + AI 速记
  daily-log/            # 口述日记 → 按固定框架归档
scripts/global-brain/   # 大脑的"全局层"部署件（技能副本 + AGENTS 规则节）+ 恢复手册
scripts/zcode-digest/   # 每日对话日结工作流脚本（配合定时任务用）
docs/自动化任务清单.md   # 全部定时任务的完整定义与重建口令（换机 5 分钟恢复）
raw笔记/                # 方法论原文 + AI 学习笔记样例
wiki摘要/ wiki概念/      # 摄取产出的样例页（看效果用）
```

## 上手三步（最简可用）

> 前提：已装 ZCode、Git，且有一个作为大脑的知识库 git 仓库（结构随意，`raw/` 存原始资料、`wiki/` 存整理稿即可）。

1. **装技能**：把 `skills/` 下 5 个文件夹复制到 `~/.zcode/skills/`；然后编辑 `brain/SKILL.md`，把「定位大脑仓库」的占位路径改成你自己仓库的实际路径。
2. **装全局规则**：把 `scripts/global-brain/AGENTS-外置大脑节.md` 的内容追加到 `~/.zcode/AGENTS.md`（没有就新建）。
3. **可选——装自动化**：照 `docs/自动化任务清单.md` 里的建法口令，让 ZCode 建日结（17:40）、制卡（18:00）、晨间复习（8:10）三个定时任务；日结依赖 `scripts/zcode-digest/`，复制到你大脑仓库的 `scripts/` 下即可。
