## Transformer 的发展

- N-gram：统计前面出现的词之后，后面一般是什么词。问题：理解不了词之间的关系

- Embedding（词向量）：用多维向量表示词，根据多维数据判断词之间的关系

- 前馈神经网络（FFN）：学习这些词的语言规律。问题：一次能接收的 token 有限，理解长度不够

- RNN（循环神经网络）：前面出现的信息一直往后面传送。问题：长期记忆能力不行

- LSTM：有长期记忆通道，模型可以处理信息，决定什么该忘掉、什么该记住。问题：token 一个一个算，效率低；距离远的 token 之间无法传递信息

- Transformer：让距离远的多个 token 可以直接建立联系，让 token 互相理解

## Attention：token 之间怎么建立联系

- Query（Q，主动）：当前 token 主动去查上面 token 的信息；其他 token（被动）的信息叫 Key（K）

- 通过 Q 和 K 的匹配度建立 token 之间的联系

- Value（V）：收集每个 token 上面的信息

- 多个 token 空间（多头注意力）：让一句话里的多个 token 弄明白相互的语义

## Transformer 的问题和解决方法

- 顺序丢失：因为 token 是并行计算的，顺序信息丢了，可以用位置编码解决

- 怎么猜词：例如「用户买了 1w 多的苹果」→ 猜出是手机。Attention 负责交流信息，FFN 负责思考 token 之间的关系，猜出内容

- 信号衰减 / 梯度消失：多层堆叠传输会导致信号衰减、梯度消失。解决：残差连接，每次只需要学习「输入到目标输出差了多少」，有利于前向传播和反向传播

## 编码器和解码器

- 编码器：只可以看到前面的 token，防止过度解读

- 解码器：用已生成 token 的 Q，对应编码器 token 的 K/V，就可以得到相似度

- 解码器三步：掩码自注意力（查看前面生成的内容）→ 交叉注意力（查看编码器输出）→ 前馈神经网络（FFN）
