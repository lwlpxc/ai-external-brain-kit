# 自动化任务清单（双机恢复手册）

> **为什么需要这页**：ZCode 的定时自动化和保存的工作流存在**每台电脑本机的 workspace 数据**里，不随 git/GitHub 同步——换电脑就"不见了"。真本资产（工作流脚本）已迁入本仓库 `scripts/zcode-digest/`，随 git 同步；本页记录全部自动化的完整配置，任何一台新电脑照本页 5 分钟重建。
> 更新纪律：新增/修改自动化时同步更新本页（改完 commit）。

## 随 git 走 vs 只在本机

| 资产 | 位置 | 随 git？ |
|---|---|---|
| 笔记/wiki/复习材料 | 仓库内 | ✅（日记除外，隐私不进 git） |
| 日结工作流脚本 | `scripts/zcode-digest/`（真本） | ✅ 2026-10-21 迁入 |
| 定时自动化（cron） | 本机 ZCode workspace 数据 | ❌ 照本页手工重建 |
| 日结水位/临时 dump | `scripts/zcode-digest/local-state/`、`tmp/`（已 gitignore） | ❌ 本机各自保留（会话库独立，水位共享会漏吃对话） |
| saved workflow 旧副本 | workspace `.zcode/workflows/` | ❌ 已废弃，真本在仓库 |

## 新电脑恢复步骤

1. clone / pull 本仓库；ZCode 打开的工作区 = 仓库的**父目录**（`.zcode` 所在层级）。
2. 对 ZCode 说：「读仓库内 docs/自动化任务清单.md，按清单把自动化全部重建」，或照下表逐条让 ZCode 建。
3. 检查：`node -v` 可用；git 凭据能 push。日结水位新机器从零起步（首跑回溯 24h），正常。
4. 双机原则：**17:40 日结两台都可以开**（各提炼各的会话库）；**8:10 复习和 18:00 制卡只在你常用的那台开**，避免同一任务双跑两遍。

## 当前自动化（4 条）

### 1. 每天 17:40 ZCode 对话日结 ✅ 建议双机都开

- 脚本：仓库内 `scripts/zcode-digest/zcode-daily-digest.workflow.ts`（path 方式运行，不依赖 saved）
- 给 ZCode 的建法口令：
  > 建一个每天 17:40 的自动化，标题「每天17:40 ZCode对话日结」，prompt 如下：
  > 「执行今天的 ZCode 对话日结：调用 CreateWorkflow 工具，source 用 path，脚本用仓库内 your-brain-repo/scripts/zcode-digest/zcode-daily-digest.workflow.ts（真本，随 git 同步；不传 args 走默认：水位窗口、项目B 63440 + 项目A 63453）。该工作流把窗口内对话的学习要点写进 your-brain-repo/raw/公司学习/对话日结/ 当天文件并 git 提交推送。完成后向用户转述：写了什么文件、各项目几条亮点、推送是否成功。失败说明原因，最多重试一次，不要自行改脚本或改水位。」

### 2. 每天 18:00 对话日结自动制卡 ⚠️ 只开一台

- 作用：把 17:40 日结提炼成 3~5 张问答卡进 `wiki/复习/每日新知卡.md`（SRS 快闪用）
- 给 ZCode 的建法口令：
  > 建一个每天 18:00 的自动化，标题「每天18:00 对话日结自动制卡」，prompt 如下：
  > 「自动制卡任务（仓库 your-brain-repo，无需用户参与）。1. cd 仓库并 git pull。2. 找今天的 raw/公司学习/对话日结/今天日期.md；不存在则用 git log --since="今天 00:00" --name-only 找 raw/ 今日新增文件代替；raw 今日无新内容则结束并汇报「今日无新内容，未制卡」。3. 通读提炼 3~5 张问答卡（面试官视角：会追问的要点、当天最典型的坑、可迁移教训；一卡一问，答案 2~3 句）。4. 追加批次到 wiki/复习/每日新知卡.md（## 批次 YYYY-MM-DD 主题 + 来源 + 状态「待首复习（到期明天，+1）」+ 编号 Q/A），更新顶部批次调度总表。5. git 只 add 本次动过的文件 + commit（YYYY-MM-DD 新增每日新知卡 N 张）+ push，失败仅告知。6. 一句话汇报制了几张卡。若 17:40 日结未跑找不到文件，汇报说明即结束，不等待不重跑。」

### 3. 每天 8:10 复习大脑（快闪卡片+主题深度）⚠️ 只开一台

- 作用：晨间复习第一段·新知卡快闪（5 分钟）+ 第二段·主题深度（SRS 到期主题，先读 wiki 页后答刁钻面试题）；成绩更新 `wiki/复习/SRS调度.md`，超纲扩展写 `raw/复习/`
- 给 ZCode 的建法口令：
  > 建一个每天 8:10 的自动化，标题「复习大脑（快闪卡片+主题深度）」，prompt 如下：
  > 「执行每日晨间复习（仓库 your-brain-repo）。1. cd 仓库 git pull。2. 读 wiki/复习/SRS调度.md、wiki/复习/每日新知卡.md、欢迎.md。3. 两段复习：A 新知快闪约5分钟——找今日到期批次（昨日 +1 首复习及 D+3/D+7/D+14/D+29 旧批次），逐卡只念问题用户口答后给答案简评；批次全对升档（间隔序列 1/2/4/7/15/30 进一档），有错重置 1 天明日重现。B 主题深度——按 SRS调度.md 到期主题每日 1 个（逾期最早优先，面试权重 BMS>C语言>通信>RTOS>公司业务>AI）：先给阅读路线让用户亲读 wiki 页面（每页盯一个点），用户读完后当刁钻面试官提 8~10 题（术语陷阱/连环追问/计算/超纲）。4. 批改 ✓/✗，超纲扩展写 raw/复习/YYYY-MM-DD-主题扩展.md 等用户说「摄取」。全对阶段+1、错1~2同档重滚、错≥3重置1天。5. 更新欢迎.md 今日学习台第一屏。6. git 只 add 本次改动文件（禁止 add -A）+ commit（YYYY-MM-DD 动词+对象 简述）+ push，失败告知。7. 用户说今天不复习就跳过不追问。」
