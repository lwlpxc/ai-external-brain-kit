# Transformer

让远距离 token 直接建立联系、互相理解的神经网络架构，是现代大模型的基石。

## 演进脉络（每个架构都是为了解决前一个的短板）

N-gram（统计词频，不懂词间关系）→ Embedding 词向量（多维向量表示词，判断词间关系）→ FFN 前馈网络（学语言规律，但一次接收 token 有限）→ RNN（信息往后传，长期记忆差）→ LSTM（加长期记忆通道决定记忘，但逐 token 计算效率低、远距离传不了信息）→ Transformer。

## Attention 机制

- **Q/K/V**：Query 主动查询，其他 token 的信息是 Key，Q-K 匹配度建立联系；Value 收集每个 token 携带的信息
- **多头注意力**：多个 token 空间并行，让一句话里多个 token 弄清相互语义

## 三个固有问题与解法

1. 并行计算丢顺序 → **位置编码**
2. 猜词分工：Attention 负责交流信息，FFN 负责思考 token 间关系（例：「用户买了 1w 多的苹果」→ 手机）
3. 多层堆叠信号衰减/梯度消失 → **残差连接**：每次只学"输入到目标输出差了多少"

## 编码器与解码器

- 编码器只看前面的 token，防过度解读
- 解码器三步：掩码自注意力（看已生成内容）→ 交叉注意力（用已生成的 Q 对编码器的 K/V 算相似度）→ FFN
